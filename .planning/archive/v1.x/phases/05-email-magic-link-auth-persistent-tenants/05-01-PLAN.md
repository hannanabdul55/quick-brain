|----------|-------------|
| lib/auth/db.ts → data/quickbrain-app.sqlite | SQLite file on local filesystem — only the Next.js process writes it |
| JWT_SECRET env var → jose HS256 signing | Secret never leaves process; must be ≥32 bytes |
| next.config.ts serverExternalPackages | Prevents bun:sqlite from being included in Edge bundle |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | lib/auth/jwt.ts JWT_SECRET | mitigate | JWT_SECRET must be ≥32 bytes (openssl rand -hex 32); AUTH-13 demo-check.sh verifies length; code reads process.env.JWT_SECRET! (throws if unset) |
| T-05-02 | Spoofing | lib/auth/db.ts prepared statements | mitigate | All SQL uses bun:sqlite prepared statements with ? params — no string interpolation; SQL injection impossible at driver level |
| T-05-03 | Information Disclosure | lib/auth/db.ts qbo_tokens_encrypted column | mitigate | Column stores AES-256-GCM blob (Phase 6 write); column defined nullable in schema; no plaintext secrets in DB |
| T-05-04 | Elevation of Privilege | lib/gbrain/brain-slug.ts BrainSlug branding | mitigate | Branded type prevents userId from silently substituting as mutex key — compile-time enforcement |
| T-05-SC | Tampering | bun add jose resend | mitigate | RESEARCH §2 Package Legitimacy Audit marks both ASSUMED-approved; operator should verify npmjs.com/package/jose and npmjs.com/package/resend repository URLs match panva/jose and resend/resend-node before running bun add |
