    ## Input Schema (pages consumed by the smb-audit skill)

    ### invoice documents (originals/invoice-*.md)
    Required frontmatter fields:
    - type: invoice
    - vendor: <human-readable vendor name, string>
    - vendor_slug: <kebab-case slug matching companies/<slug>.md filename>
    - date: <YYYY-MM-DD>
    - amount: <number, USD unless currency specified>
    - currency: <ISO 4217, default USD>

    Body must contain wikilink: [[companies/<vendor_slug>]]

    ### bank-statement documents (originals/bank-statement-*.md)
    Required fields:
    - type: bank-statement
    - date: <YYYY-MM-DD> (statement period start)

    Body debit line format (used by the duplicate and missing-invoice rules):
    `- YYYY-MM-DD: $X.XX debit — <description> [[companies/<vendor_slug>]]`
    The regex the detector uses: /^-\s+(\d{4}-\d{2}-\d{2}):\s+\$([0-9,]+\.\d{2})\s+debit\s+—.*\[\[(?:companies\/)?([a-z0-9-]+)\]\]/

    ### company documents (companies/<slug>.md)
    Required fields:
    - type: vendor (or company)
    - vendor: <human-readable name>
    - slug: <kebab-case, must match filename without .md>

    Body timeline bullets used by ghost-saas rule:
    `- YYYY-MM-DD: <event description>`

    ## Output Schema (pages written by the smb-audit skill)

    ### concepts/march-anomaly-summary.md
    Frontmatter: type: concept, title, date (YYYY-MM-31 of last month), tags, plus anomalies: YAML list.
    Each anomalies list entry:
    - severity: high | medium | low
    - dollar_impact: <number>
    - anomaly_type: price-hike | duplicate | ghost-saas | missing-invoice
    - vendor_slug: <slug matching companies/ page>

    Body bullet format (MUST match lib/insights/anomalies.ts bulletRegex):
    `- YYYY-MM-DD: [[companies/<vendor_slug>]] <description>`

    ### concepts/recurring-charges.md
    Frontmatter: type: concept, title, date, tags.
    Body bullet format:
    `- YYYY-MM-31: [[companies/<vendor>]] — $X.XX in Month YYYY, active across N months; last meaningful vendor event YYYY-MM-DD (N days ago)[⚠ GHOST]`

    ## Wikilink Convention
    All cross-references to vendor pages MUST use the full path form: [[companies/<slug>]].
    Bare [[slug]] wikilinks without the companies/ prefix are NOT matched by the
    anomaly parser or the gbrain WIKILINK_RE graph extractor.

    ## Severity Tiers
    - high: dollar_impact > 100 OR anomaly_type is ghost-saas OR missing-invoice
    - medium: 30 <= dollar_impact <= 100
    - low: dollar_impact < 30

    - TxnDate → date (NOT MetaData.LastUpdatedTime)
    - TotalAmt → amount
    - VendorRef.name → vendor (human-readable)
    - VendorRef.name slugified → vendor_slug
    Wikilinks in QBO-sourced pages MUST use qbo-prefixed slugs: [[companies/qbo-<slug>]].

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GBRAIN_HOME env → filesystem reads | The sourceDir passed to runDetection controls which files are read; a malicious or path-traversal value could escape brains/ |
| shell-job cmd parameter → child process | The cmd string passed to gbrain jobs submit shell is operator-controlled; in production would require sanitisation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | lib/audit/anomaly-detector.ts writeFile | mitigate | validate that GBRAIN_HOME resolves inside BRAINS_ROOT or FIXTURES_ROOT before any write; reject paths containing ".." |
| T-04-02 | Information Disclosure | concepts/ pages written to brain dir | accept | brain dirs are local filesystem only; no network exposure in Phase 4 |
| T-04-03 | Denial of Service | skill writing to wrong dir if GBRAIN_HOME is empty string | mitigate | explicit GBRAIN_HOME presence check in smb-audit.mjs before calling runDetection; exit(1) with clear error |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | Phase 4 adds no new npm packages; existing bun lockfile covers all dependencies |
</threat_model>
