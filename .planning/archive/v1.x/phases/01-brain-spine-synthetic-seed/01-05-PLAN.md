<objective>
Wire all prior plans into a single end-to-end seed pipeline: validate the dataset → initialize a gbrain brain at `brains/seed/` → set model defaults → copy synthetic data in → run `gbrain import` → run the anomaly detector → re-import the generated concepts pages. One command, idempotent, fail-loud, and the artifact (`brains/seed/`) is the source-of-truth that Phase 2 onboarding will `cp -r` from.

Purpose: This is the integration moment for Phase 1. Until now, every plan has been building separate pieces (harness, dataset, detector). This plan glues them together with the gbrain CLI and confirms the entire data path works before the smoke gate in plan 01-06 runs the actual demo queries.

Output: `scripts/seed.sh` (bash, primary) plus optionally `scripts/seed.ts` (only if the shell version gets unwieldy — planner's call). `bun run seed` succeeds end-to-end in a clean shell, and re-running it rebuilds `brains/seed/` from scratch deterministically.
</objective>
