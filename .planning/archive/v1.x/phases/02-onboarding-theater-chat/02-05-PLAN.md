Build the dashboard route and the visual chat surface — input, send button, message list, scroll area, and three hardcoded suggested-question chips. Purpose: Without a dashboard route, the redirect from Plan 04 lands on a 404 and the demo collapses at the "operator arrives" beat. This plan provides the chrome and message-state plumbing; Plan 06 provides the backend it talks to.

Output: A working `/dash/<tenantId>` page that renders the chat UI, three suggested chips, an input + send affordance, a thinking-state skeleton, and a markdown-rendered assistant response (markdown renderer comes from Plan 06).
</objective>
