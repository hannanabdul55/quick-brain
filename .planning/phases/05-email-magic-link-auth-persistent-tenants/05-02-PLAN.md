<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → POST /api/auth/send-link | Untrusted email input crosses here; zod validates format |
| Email client → GET /api/auth/verify | Magic-link URL with JWT token — treated as untrusted until jose verification |
| verify route → bun:sqlite | Atomic UPDATE guards token reuse; prepared statements prevent SQL injection |
| verify route → Set-Cookie | HttpOnly prevents JS access; SameSite=Lax prevents CSRF on state-changing GETs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05 | Spoofing | Token forgery | mitigate | jose jwtVerify with HS256 secret; tampered tokens throw JWSInvalid → generic error (no oracle) |
| T-05-06 | Repudiation | Token replay | mitigate | Atomic `UPDATE … WHERE used=0` + result.changes guard; concurrent redemption race handled |
| T-05-07 | Information Disclosure | Email enumeration | mitigate | send-link always returns `{ ok: true }` regardless of email existence; 429 shape reveals rate-limit but not account existence |
| T-05-08 | Elevation of Privilege | Session fixation | mitigate | Session cookie issued only AFTER token verification; new cookie on every verify call |
| T-05-09 | Repudiation | CSRF on sign-out | accept | Sign-out is POST; SameSite=Lax blocks cross-site POSTs from third-party frames; low impact (worst case: user signed out, not data exposed) |
| T-05-10 | Tampering | SQL injection on email field | mitigate | All SQL uses bun:sqlite prepared statements with ? parameters |
| T-05-11 | Denial of Service | Rate-limit bypass via X-Forwarded-For spoofing | accept | Rate limit keyed by email (not IP); email spoofing is bounded by JWT verification; acceptable for hackathon threat model |
| T-05-SC | Tampering | bun add jose resend (already installed in Plan 01) | mitigate | RESEARCH §2 audit: both packages verified; no postinstall scripts; operator confirmed via npmjs.com repository URLs |
</threat_model>
