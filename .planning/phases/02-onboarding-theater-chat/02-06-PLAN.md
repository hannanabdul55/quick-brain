<objective>
Implement the chat backend: POST `/api/tenants/<id>/chat` spawns `gbrain query --no-expand` against the tenant's brain, streams the full markdown response as a single SSE `answer` frame, emits an `error` frame on 30s timeout or non-zero exit, and closes. Also implement the client markdown renderer (`react-markdown + remark-gfm`) so citations appear as inline text. Patch `lib/gbrain/index.ts`'s `query()` helper to accept `{ expand?: boolean }` with default `false`, preserving the Phase 1 API while making `--no-expand` the new default.

Purpose: This is the half of the chat surface that produces real answers. Without it, the dashboard chat box (Plan 05) has no backend and the demo collapses at the moneyshot beat. The `--no-expand` decision sidesteps the Phase 1 gotcha where chat queries take 3+ minutes.

Output: `/api/tenants/[id]/chat` SSE endpoint, a react-markdown renderer, an updated `query()` helper, and (best-effort) the CHAT-05 system-prompt-style guidance.
</objective>
