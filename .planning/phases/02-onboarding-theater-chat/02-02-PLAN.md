<objective>
Implement the tenant-creation API. POST /api/tenants accepts the onboarding form payload, validates it with zod, slugifies the business name, resolves slug collisions, copies `brains/seed/` to `brains/<slug>/`, registers the tenant in the in-memory Map, and returns the tenantId.

Purpose: This is the synchronous half of onboarding (ONBD-03 — "all in under 2 seconds wall-clock"). The 30-45s narrated SSE in Plan 03 only runs AFTER this Route Handler returns the tenantId. Keeping creation fast and lean preserves the demo timing budget.

Output: A `/api/tenants` POST endpoint, a testable `createTenant()` domain function in `lib/onboarding/`, and a zod schema shared by client and server.
</objective>
