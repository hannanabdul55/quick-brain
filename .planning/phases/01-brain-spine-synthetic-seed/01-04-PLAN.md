<objective>
Build the hand-rolled TypeScript anomaly detector that reads a gbrain brain dir (post-import is not required — the detector can read either `data/maras-coffee/` directly OR the copied `brains/seed/` after import; both work because gbrain import preserves the source markdown). It applies 3 rule functions and writes two `concepts/` markdown pages that gbrain query will surface when the operator asks "what was weird about last month?".

Purpose: DATA-08 requires this. The detector replaces what a custom `smb-audit` gbrain skill would do — and it ships in ~1h instead of the full skill's multi-hour cost. Output pages feed back INTO gbrain's graph via wikilinks, so `gbrain graph-query beanstalk-roasters --depth 2` can return the anomaly page as a neighbor.

Output: One TypeScript file with the 3 rule functions, a small loader helper, and a CLI entry point invoked by `scripts/seed.sh` (plan 01-05). Unit tests prove all 3 rules fire on the locked-in fixture.
</objective>

```typescript
// scripts/lib/dataset-loader.ts
export interface ParsedDoc {
  filename: string;          // e.g. 'invoice-beanstalk-2026-03-05.md'
  slug: string;              // filename without .md
  frontmatter: Record<string, unknown>;
  body: string;              // full body, post-frontmatter
}
export function loadOriginals(brainDir: string): ParsedDoc[];   // brainDir/originals/*.md
export function loadCompanies(brainDir: string): ParsedDoc[];   // brainDir/companies/*.md

// scripts/detect-anomalies.ts
export interface AnomalyFinding {
  id: string;                    // e.g. 'price-hike-beanstalk-2026-03'
  title: string;                 // H2 text
  description: string;           // plain-English prose
  impactUsd: number;             // for **Impact:** $N
  sourceOriginals: string[];     // file slugs (no .md) for wikilinks
  sourceCompanies: string[];     // company slugs for wikilinks
  category: 'price-hike' | 'duplicate-charge' | 'ghost-saas';
}
export function detectPriceHike(docs: ParsedDoc[]): AnomalyFinding[];
export function detectDuplicateCharges(docs: ParsedDoc[]): AnomalyFinding[];
export function detectGhostSaaS(originals: ParsedDoc[], companies: ParsedDoc[]): AnomalyFinding[];
```
