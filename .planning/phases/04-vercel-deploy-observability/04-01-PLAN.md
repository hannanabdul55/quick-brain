<objective>
De-risk the single highest-risk item in Phase 4: confirm the in-process gbrain
path (refactored in Phase 3) actually compiles under `next build` and runs under
`next start`. The in-process gbrain code has only ever run under the Bun dev
server — never through a production webpack/Turbopack build. gbrain ships raw
TypeScript with WASM dependencies (`@electric-sql/pglite`, `tree-sitter-wasms`,
`web-tree-sitter`) and is loaded via a runtime computed dynamic-import shim.

This plan adds `serverExternalPackages: ['gbrain']` to `next.config.ts`, creates a
minimal `vercel.json`, and gates the result behind a local build + chat smoke
test. No Vercel deploy is attempted here — if the build fails, the deploy plan
(04-03) must not proceed on an unverified build.

Purpose: The Vercel deploy in 04-03 depends on a build that is currently
unverified. This plan converts RESEARCH.md Open Question 1 / Pitfall 1 /
Assumption A4 into a hard pass/fail gate before any deploy work.
Output: A modified `next.config.ts`, a minimal `vercel.json`, and a verified-good
local production build of the in-process gbrain chat route.
</objective>
