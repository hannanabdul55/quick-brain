Build the generic job data layer: the `JobKind`-keyed contract (types), the zod trigger schema, the Supabase Postgres job-row store, the operation registry, and the DDL that creates the `jobs` table. <threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App connection -> Supabase Postgres `app.jobs` table | The app reads/writes job rows; gbrain's auto-RLS event trigger may target tables in the same database |
| Job `params` (later from an HTTP body) -> SQL INSERT | `params` originates from the trigger route's request body and is written into the table |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05 | Tampering | `lib/jobs/store.ts` SQL | mitigate | All SQL uses the `postgres` package's tagged-template parameterization (`sql\`... ${value}\``); `params` is written via `sql.json(params)`. No string concatenation of values into SQL — SQL injection via `params` is structurally blocked |
| T-05-06 | Information Disclosure | `lib/jobs/store.ts` `failJob` | mitigate | `failJob` sanitizes `error` before storing: sliced to 500 chars and `postgres://` connection strings stripped. No raw stack trace or DB URL reaches the `app.jobs.error` column (which the status route later returns to the browser). Mirrors `probes.ts` T-04-02 and the chat route's stderr-slicing |
| T-05-07 | Information Disclosure | `app.jobs.id` | mitigate | `id` defaults to `gen_random_uuid()` (122-bit) — not a sequential integer. A `jobId` acts as an unguessable capability token; enumeration of other jobs' rows is infeasible. Per-user scoping arrives in Phase 6 |
| T-05-08 | Denial of Service | gbrain auto-RLS event trigger silently locking `app.jobs` | mitigate | The table is created in a separate `app` schema (Pitfall 4 primary hedge); `scripts/setup-jobs-table.ts` runs an INSERT-then-SELECT visibility check and fails loudly with a remediation hint if the trigger still catches it. The "silent zero rows" failure mode cannot pass unnoticed |
| T-05-SC | Tampering | npm/package installs | accept | This plan installs no packages — `postgres` and `zod` are already installed. No supply-chain surface |
</threat_model>
