<objective>
Make gbrain's query AND chat paths source-scopable so per-user brain isolation
(AUTH-05) is mechanically possible. RESEARCH.md's Spike Addendum proved the
query/retrieval path (`hybridSearch`) already accepts `sourceId` natively, but
the chat path (`runThink` -> `runGather`) carries NO source field and would
synthesize answers over every user's pages. This plan: (1) installs
`patch-package` and commits a patch threading `sourceId` through gbrain's
`think` internals (D-12), (2) updates the `@/types/gbrain` shim to expose
`sourceId` on `HybridSearchOpts` and `RunThinkOpts`, and (3) threads a
`sourceId` parameter through `queryInProcess` and `think()`.

Purpose: Without a source-scopable chat path, AUTH-05 cannot be met for the chat
surface — this is the explicit D-12 scope addition. The actual wiring of the
session-derived `source_id` into these calls happens in plan 06-05; this plan
makes the plumbing exist.
Output: A committed gbrain patch, a `postinstall` script, an updated shim, and
`sourceId`-threaded `engine.ts` / `client.ts`.
</objective>
