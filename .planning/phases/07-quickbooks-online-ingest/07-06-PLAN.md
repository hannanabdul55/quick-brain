<objective>
The four API route handlers that power the QBO connection lifecycle: start OAuth, handle callback (token exchange + job enqueue), resync (wipe + re-enqueue), and disconnect (revoke + clear columns).

Purpose: These routes are the user-facing entry points for the entire QBO ingest flow. The callback route is especially critical — it validates the OAuth state JWT, exchanges the code for tokens, stores them encrypted, creates a job row, fires the Inngest event, and redirects to the sync-progress screen.
Output: Four new Next.js App Router route handler files in app/api/connections/quickbooks/.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Intuit OAuth redirect → callback route | code, state, realmId are from Intuit — state must be cryptographically verified before code exchange |
| resync request → wipeQBODocs | brainSlug is session-derived (resolveTenant), not URL-param-derived |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-20 | Spoofing | OAuth callback state param | mitigate | verifyStateJwt throws on invalid/expired state; callback returns 400 and aborts before any token exchange |
| T-07-21 | Spoofing | CSRF on callback | mitigate | verifyStateJwt payload user_id cross-checked against active session userId where available; 10-min TTL prevents stale state replay |
| T-07-22 | Information Disclosure | callback/route.ts token handling | mitigate | exchange() result never logged; sanitizeError strips token fields from any error object before console.warn; no token values in redirect URL |
| T-07-23 | Information Disclosure | Connector_revoked enumeration timing oracle | mitigate | disconnect returns { ok: true } regardless of prior connection state; response body and timing do not reveal whether user had a connection |
| T-07-24 | Tampering | resync wipeQBODocs path | mitigate | brainSlug comes from resolveTenant() (session-derived, never URL param); wipeQBODocs has its own path-traversal guard (Plan 04) |
| T-07-SC | Tampering | npm/pip/cargo installs | accept | No new npm packages installed |
</threat_model>
