<!-- From RESEARCH.md Domain 1 — Token exchange request shape -->
Token exchange POST:
  URL: QBO_OAUTH_TOKEN_URL
  Headers: Authorization: "Basic base64(client_id:client_secret)"
           Content-Type: "application/x-www-form-urlencoded"
           Accept: "application/json"
  Body: grant_type=authorization_code&code=CODE&redirect_uri=REDIRECT_URI

Token refresh POST:
  Body: grant_type=refresh_token&refresh_token=REFRESH_TOKEN

Token response shape:
  { token_type, access_token, expires_in, refresh_token, x_refresh_token_expires_in }
  expires_in: 3600 seconds
  x_refresh_token_expires_in: 8640000 seconds (100 days)

Revoke POST:
  URL: QBO_OAUTH_REVOKE_URL
  Body: token=TOKEN (revoking either invalidates both)

<!-- From CONTEXT.md D-05 — CRITICAL refresh discipline -->

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Intuit OAuth server → callback | OAuth callback receives code + state from Intuit — both are untrusted until state JWT verified |
| app → Intuit token endpoint | Client secret must never appear in logs or error messages |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-05 | Spoofing | OAuth state parameter | mitigate | buildStateJwt creates HS256 JWT with {user_id, nonce, 10-min TTL}; verifyStateJwt throws on tampered/expired state — defeats CSRF (D-04) |
| T-07-06 | Spoofing | OAuth code replay | mitigate | 10-min TTL on signed state JWT; replayed code returns error from Intuit (code is single-use); state nonce (crypto.randomUUID()) prevents state reuse |
| T-07-07 | Information Disclosure | lib/connectors/qbo/oauth.ts | mitigate | No console.log/console.error calls; OAuthError carries only error code string, not token values; exchange() discards raw response body after single parse |
| T-07-08 | Tampering | Refresh token rotation | mitigate | refresh() calls persistTokens() BEFORE returning — structural code order enforces the rotation discipline; stale-token invalid_grant cannot be triggered by a missed persist |
| T-07-SC | Tampering | npm/pip/cargo installs | accept | No new npm packages installed (native fetch, node:crypto, existing jose via lib/auth/tokens.ts) |
</threat_model>
