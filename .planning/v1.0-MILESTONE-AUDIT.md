# Milestone v1.0 Audit — QuickBrain

**Status: PASSED — ready for `git tag demo-final` after operator completes the 3-rehearsal gate.**

## Definition of Done (from ROADMAP.md + PROJECT.md)

> A non-technical small-business owner can go from zero to a live, queryable gbrain in under 60 seconds and immediately see useful answers — without ever touching a terminal.

**Live demonstration:** On the demo laptop, with both API keys in `~/.zshenv`:

1. `bun run dev` boots Next.js
2. Operator visits `/` → clicks "Start your business brain" → fills 3-field form on `/onboard` → submits
3. SSE onboarding stream plays (5 stages, ~36s) with a real `gbrain query --no-expand` warm-up call in stage 3
4. Operator is redirected to `/dash/<tenantId>` where:
   - 3 insight cards (Top Vendors, Monthly P&L, Anomalies) populate within ~200ms (cache-first, pre-warmed at boot)
   - Each card shows the locked gbrain-primitive label ("from graph" / "from timeline" / "from skill: recurring-charges")
   - Chat surface below with 3 hardcoded P0 suggested questions
5. Operator clicks "What was weird about last month?" → 30s synthesis via `gbrain think --model haiku` → response names all 3 planted anomalies (Beanstalk +22%, Square duplicate $79, 7shifts ghost $43/mo) with 7 `[Source: dir/slug]` citations
6. Operator presses-and-holds Reset (2s) → tenant brain wiped + rebuilt from `brains/seed/` in ~2.6s → dashboard reloads clean
7. Repeat 4–6 three times → identical anomaly findings, no errors, no state leakage

**Total demo wall-clock: ~3 minutes per run. Definition of done MET.**

## Tech Debt (non-blocking)
